# Sp4You — Дитячі свята

Сайт агентства дитячих свят з автоматичною галереєю фото.

## Як додати фото в галерею

1. Сожміть фото на [tinypng.com](https://tinypng.com)
2. Покладіть фото в папку `gallery/`
3. Запуште на GitHub
4. GitHub Action автоматично створить мініатюри та оновить `gallery.json`
5. Через ~30 секунд фото з'являться на сайті

## Структура

```
├── index.html          # Головна сторінка
├── styles.css          # Стилі
├── gallery/            # Фото (сюди додавати)
│   └── thumbs/         # Мініатюри (створюються автоматично)
├── gallery.json        # Список фото (створюється автоматично)
└── .github/workflows/
    └── gallery.yml     # Автоматизація
```
